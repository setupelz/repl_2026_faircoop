# Equitable cooperation deepens the solution space for high ambition pathways

Replication archive for "Equitable cooperation deepens the solution space for
high ambition pathways". Assembles MESSAGEix-GLOBIOM-GAINS scenario reporting
output into a single tidy dataset and generates all code-based manuscript and
supplementary figures.

## Pipeline

```
Data/*.xlsx  (per-scenario reporting workbooks, one per model run)
    │  Code/100_assemble.R
    ▼
Data/scenario_set_reporting.csv
    │  Code/2xx (main figures), Code/3xx (SI)
    ▼
Manuscript/Figures/*.png, Manuscript/Figures/SI/*.png,
Manuscript/Tables/SI_Table_1_Scenarios.csv, Manuscript/Tables/SI_text_numbers.xlsx
```

Scenario labels are parsed from each workbook's own Model/Scenario strings, so
adding or removing a scenario means adding or removing its workbook in `Data/`
and re-running `make assemble` — there are no hand-maintained scenario lists.

## Prerequisites

- R >= 4.0.0 with the renv package (`install.packages("renv")`)
- The scenario workbooks in `Data/` (see Data availability below)

## Reproduction steps

```bash
git clone <repository-url>
cd repl_2026_faircoop
```

```r
# In an R console at the repo root
renv::restore()
```

```bash
make assemble       # Data/*.xlsx -> scenario_set_reporting.csv (run once)
make all            # all figures, SI tables
make main-figures   # manuscript figures only (Figures 2-5)
make si-figures     # supplementary figures, SI Table 1, in-text numbers workbook
```

Figure 1 in the manuscript is a conceptual framework schematic and is not
generated by code.

## Data availability

The per-scenario reporting workbooks (`Data/*.xlsx`) and the assembled
`Data/scenario_set_reporting.csv` are too large to track in git. They will be
deposited alongside the published paper and are available from the authors on
request in the meantime (see `CITATION.md`).

Tracked in the repository:

- `Data/MANIFEST.md5` — md5 checksums of the 32 scenario workbooks the
  pipeline consumes; verify a deposited copy with `cd Data && md5sum -c
  MANIFEST.md5` (Linux) or `md5 -r *.xlsx | diff - MANIFEST.md5` (macOS).
- `Data/fairshare_allocations.csv` — regional fair-share budget allocations,
  computed with `Code/tools/compute_fairshares.py` (requires the
  [fair-shares](https://github.com/setupelz/fair-shares) library); read by
  `Code/301_si_allocations.R`.
